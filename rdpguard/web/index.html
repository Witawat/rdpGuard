ยินดีต้อนรับ

RDPGuard จะเฝ้าดูการล็อกอิน RDP ของเครื่องนี้ หากพบ IP ใดพยายามเดารหัสผ่านซ้ำ ๆ (ค่าเริ่มต้น: 5 ครั้งใน 10 นาที) ระบบจะบล็อก IP นั้นด้วย Windows Firewall อัตโนมัติ และปลดให้เองเมื่อครบกำหนดเวลา

ตั้งค่าคร่าว ๆ 4 ขั้นตอน ใช้เวลาไม่ถึง 1 นาที

แนะนำ: ถ้าต้องการให้เฝ้าระวังตลอด 24 ชม. แม้ปิดหน้าต่างนี้ ให้ปิดโปรแกรมแล้วติดตั้งเป็น Windows Service ด้วย install.bat

การตรวจจับ

ตั้งความไวของการบล็อก — ยิ่งน้อยยิ่งกันเร็ว แต่เสี่ยงบล็อกคนที่พิมพ์รหัสผิดเอง

    Windows Service

    รันเป็น service = เฝ้าระวังตลอด 24 ชม. แม้ปิดหน้าต่าง/ไม่มีใครล็อกอิน
    กำลังโหลด...

    เหตุการณ์ล่าสุด

    เวลา (UTC)IPผู้ใช้โดเมนLogonTypeแหล่งประเภท
    ยังไม่มีเหตุการณ์

    IP ที่ถูกบล็อก

    หมดอายุอัตโนมัติตามเวลาที่ตั้ง
    IPประเทศเหตุผลที่มาบล็อกเมื่อ (UTC)หมดอายุ (UTC)
    ปุ่ม "ตรวจ cmd" = คัดลอกคำสั่ง Windows ตรวจสอบ rule + event log ของ IP นั้นไปวางใน Command Prompt (admin)
    ใช้เมื่อถูกล็อกตัวเอง — ปลดทุก IP ที่ถูกบล็อกทันที
    ยังไม่มี IP ถูกบล็อก

    Whitelist

    เพิ่มแล้วปลดบล็อกทันที + ไม่บล็อกเด็ดขาด
    IPประเทศหมายเหตุ
    ว่างเปล่า

    Blacklist

    เพิ่มแล้วบล็อกทันที (สร้าง rule เลย) — ลบ = ปลดบล็อก
    IPประเทศหมายเหตุ
    ว่างเปล่า

    ประวัติการบล็อก

    IPที่มาบล็อกเมื่อปลดเมื่อโดย
    ยังไม่มีประวัติ

    Audit Log

    เวลาผู้กระทำการกระทำเป้าหมายผล
    ยังไม่มี Audit Log

    ตั้งค่า

    ชนิดผู้ใช้Session IDสถานะเริ่มเมื่อ
    ไม่มี session (หรือไม่มีสิทธิ์อ่าน — service/SYSTEM อ่านได้)
